# Отчёт по лабораторной работе №2

**Тема:** класс с ручным управлением памятью. RAII и правило пяти.

**Семейство:** A — String.

**Вариант:** 5.

## Цель работы

Научиться работать с динамической памятью внутри класса, реализовать копирование,
перемещение и безопасное присваивание объектов.

## Задание

Реализовать строковый класс `String` на C++20 с хранением символов в массиве
`char*`. Для управления памятью использовать `new[]` и `delete[]`.
Добавить методы для работы со строкой и написать тесты Google Test.

По варианту 5 нужно реализовать метод `count_char(char c) const`, который
возвращает количество вхождений символа в строку.

## Ход работы

В классе хранятся указатель на массив `data_`, длина строки `size_` и ёмкость
буфера `capacity_`. Под завершающий символ `'\0'` выделяется дополнительный байт.
Начальная ёмкость пустой строки равна 1. Когда места не хватает, ёмкость
увеличивается вдвое до нужного размера.

Конструктор копирования создаёт отдельный массив и копирует в него символы.
Конструктор перемещения забирает буфер, а исходный объект становится пустым.
Деструктор освобождает массив через `delete[]`.

Оператор присваивания принимает объект по значению и обменивает его поля
с текущим объектом через `swap`. После этого старый буфер освобождается
при уничтожении временного объекта. Это позволяет безопасно выполнять
самоприсваивание.

Реализованы методы `size`, `capacity`, `empty`, `c_str`, `reserve`, `push_back`,
`append`, `find` и `print`. При добавлении строки учитывается случай, когда
источник находится в собственном буфере. Размер проверяется на переполнение.

Метод `count_char` проходит по символам от начала строки до `size_` и увеличивает
счётчик при совпадении. Завершающий нулевой символ не учитывается.
Сложность метода — O(n), дополнительная память — O(1).

## Проверка работы

Для сборки использованы CMake и компилятор с поддержкой C++20.
В папке `.devcontainer` настроено окружение по образцу первой лабораторной.
Для работы в нём папка `lab2` открывается в VS Code через Reopen in Container.
При создании контейнера проект собирается автоматически. Google Test
загружается через CMake, поэтому для первой сборки нужен доступ к GitHub.
Написано 22 теста Google Test. Проверены основные методы, копирование,
перемещение, самоприсваивание, работа с пустой строкой и одним символом,
добавление строк и подсчёт вхождений символа.

Все 22 теста прошли под AddressSanitizer с отключённой проверкой утечек
(`ASAN_OPTIONS=detect_leaks=0`). Проверить утечки в текущем окружении
не удалось из-за ограничения LeakSanitizer.

Результат запуска демонстрационной программы:

```text
Hello, World!
find("World") = 7
count_char('l') = 3
s4 = Hello
```

## Вывод

В работе реализован класс `String` с ручным управлением памятью,
копированием и перемещением объектов. Для присваивания использована идиома
copy-and-swap. Метод варианта `count_char` подсчитывает число вхождений символа.
Работа класса проверена модульными тестами.
