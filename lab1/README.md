# Лабораторная работа 1 — вариант 3

МАИ, кафедра 806. Язык — C++ 20, система сборки — CMake 3.16+, тестирование — Google Test.
**Номер варианта: 3** (семейство A — линейный динамический массив).

## Задание варианта 3

1. Сортировка вставками по возрастанию.
2. `void array_rotate_left(int* arr, std::size_t size, std::size_t k)` — циклический сдвиг
   влево на `k`, реализован разворотом трёх отрезков.
3. Бинарный поиск с возвратом найденного индекса через out-параметр.

Контрольный пример: `{4, 2, 5, 1, 3}` → сортировка `{1, 2, 3, 4, 5}` →
сдвиг на `k = 2` → `{3, 4, 5, 1, 2}`.

## Часть 1. Программа с текстовым меню

`main.cpp` — консольная программа, вся логика вынесена в библиотеку чистых функций
`array_ops.h` / `array_ops.cpp`.

Меню: `1` создать массив · `2`/`6` напечатать · `3` вставить элемент · `4` удалить элемент ·
`5` изменить размер · `7` алгоритм варианта (сортировка + сдвиг влево) ·
`8` бинарный поиск · `0` выход.

## Часть 2. CMake и Google Test

`test_variant.cpp` — 21 тест (по заданию требуется не менее 10): создание и удаление
массива, изменение размера, вставка в середину / в префикс / в конец, удаление элемента,
бинарный поиск, сортировка вставками и сдвиг влево на контрольном примере варианта.

```bash
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Все 21 тест проходят, сборка без предупреждений (`-Wall -Wextra -Wpedantic`).

## Выполнение требований задания

- Память только вручную: `new[]` / `delete[]`, после удаления указатель обнуляется, утечек нет.
- Не используются запрещённые конструкции: классы, конструкторы, семантика
  копирования/перемещения, `std::string`, `std::vector`, `std::array`, умные указатели.
- Корректный ввод: каждый `std::cin` проверяется с `clear()` / `ignore()`, программа не падает.
- Устойчивость к пустой структуре: массив длины 0 обрабатывается корректно.
- Каждая операция выводит понятный результат (массив, длину, найденные значения).
